# 🌟 Features

SplitZen is designed to make expense tracking and settling debts as frictionless as possible. Here is a detailed breakdown of the core features:

### 1. Dashboard
- **Comprehensive View**: Instantly see your total balances across all expenses.
- **Debt Tracking**: Clearly view what you owe to others and what is owed to you.
- **Activity Feed**: View recent expenses and settlements directly from the dashboard.

### 2. Groups
- **Contextual Tracking**: Create dedicated groups for trips, apartments, roommates, or special events to keep related expenses organized in one place.
- **Group Management**: Add or remove members easily.
- **Group Balances**: See aggregated balances for specific groups.

### 3. Expense Tracking
- **Easy Entry**: Add new expenses with intuitive forms.
- **Flexible Splitting**: Split costs equally, by percentage, or by exact custom amounts.
- **Payer Selection**: Specify exactly who paid for the expense (which can be different from who is creating the expense).

### 4. Settlements
- **Record Payments**: Easily record cash or external transfers as settlements to clear debts.
- **Clear Activity**: Settlements are explicitly tracked and adjust the overall balances for both users involved.

### 5. Real-time Sync (Powered by Convex)
- All expenses, group modifications, and balance updates sync in real-time across all connected devices. No manual refresh required.

### 6. Secure Authentication
- Built on top of **Clerk**, providing seamless user login, registration, and session management.

### 7. Background Processing & Notifications
- **Inngest** handles background jobs to ensure smooth processing for complex calculations or external integrations.
- **Resend** is integrated for reliable email delivery (such as notifications or invites).

### 8. Beautiful UI
- A modern, responsive, and accessible interface built with **Radix UI**, **Tailwind CSS v4**, and **shadcn/ui**. Features dark mode support out of the box.
